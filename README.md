# Shutdown-Utility
A quick shutdown utility. Useful for installing games overnight, rendering projects, and more.


How to use:

Windows, Linux, and MacOS:


Requirements:


An updated Python



Step 1: Download the program. Then, type
```
cd "Location of install"
```
Step 2: type
```
python ShutdownUtil.py
```
Then use it!
